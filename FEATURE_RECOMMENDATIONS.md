# Rekomendasi Fitur Lanjutan untuk Ubuntu Portfolio

Berikut adalah daftar ide dan konsep fitur lanjutan yang dapat diimplementasikan ke depannya untuk semakin menyempurnakan pengalaman desktop OS portofolio Rafida Aziz:

---

### 1. ⚙️ Ubuntu Settings Center (Jendela Pengaturan GUI)
* **Deskripsi:** Jendela preferensi sistem resmi yang dapat diakses melalui App Launcher atau icon dock.
* **Fitur Utama:**
  * **Wallpaper Picker:** Pemilih tema/wallpaper visual dengan thumbnail klik (Ubuntu, Matrix, Cyberpunk).
  * **Audio FX Toggle:** Switch mute/unmute efek suara ketikan mechanical keyboard terminal.
  * **Terminal Customizer:** Pilihan ukuran font (Compact, Regular, Large) dan warna kursor.
  * **About System:** Halaman rincian hardware hypervisor dan versi kernel portofolio.

---

### 2. 🪟 Real Window Minimize & Dock Task Management
* **Deskripsi:** Mengembalikan interaktivitas tombol minimize dan sinkronisasi status aktif ke dock.
* **Fitur Utama:**
  * Tombol kuning (Minimize) memperkecil jendela ke icon dock terkait.
  * Indikator titik oranye menyala pada icon dock saat jendela diminimalkan / berjalan di background.
  * Klik icon dock untuk restore jendela kembali ke fokus utama.

---

### 3. ⌨️ Global OS Keyboard Shortcuts (Linux Hotkeys)
* **Deskripsi:** Dukungan shortcut keyboard global bagi pengguna power-user/recruiter tech-savvy.
* **Shortcut:**
  * `Ctrl + Alt + T` : Buka / fokus ke Terminal `meet-rafida.sh`.
  * `Super / Windows Key` : Buka / tutup GNOME App Launcher overlay.
  * `Alt + F4` : Tutup jendela yang sedang aktif.
  * `Ctrl + L` : Membersihkan buffer layar terminal (`clear`).

---

### 4. 🔋 Quick Settings Dropdown (Pojok Kanan Atas: Wifi, Audio, Power)
* **Deskripsi:** Menu popover GNOME di pojok kanan atas sistem bar.
* **Fitur Utama:**
  * Slider kontrol volume audio sintetis.
  * Status koneksi virtual: *Connected to Nexatriv-Fiber (1 Gbps)*.
  * Tombol **Restart / Reboot System** yang memicu animasi shutdown dan mengulang Linux Boot Screen.

---

### 5. 🎵 Ubuntu Rhythmbox / Lo-Fi Audio Widget
* **Deskripsi:** Widget pemutar musik ambient minimalis.
* **Fitur Utama:**
  * Memutar alunan Lo-Fi Coding Beats / Synthwave tanpa copyright.
  * Tombol Play/Pause dan animasi bar audio visualizer mini di top bar.

---

### 6. 🗑️ Interactive Trash Can (Desktop / Dock)
* **Deskripsi:** Tempat sampah khas Ubuntu dengan muatan humor developer.
* **Isi File Interaktif:**
  * `bugs_fixed_in_production.log`
  * `legacy_php_monolith_2020.zip`
  * `unnecessary_dependencies/`
